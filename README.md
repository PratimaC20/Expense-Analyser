# 💰 AI Expense Analyser

## 📝 Project Overview
AI Expense Analyser is an interactive financial assistant built using Streamlit and powered by the Google GenAI SDK (`gemini-3.6-flash`). The application allows users to input their monthly income and itemized expenses, then leverages artificial intelligence to produce instant, actionable financial breakdowns, tailored savings suggestions, and personalized budgeting strategies.   

## ✨ Features
- **Dynamic Input Processing:** Capture total monthly income along with unstructured, multi-line expense entries.   
- **Customizable Analysis Modes:** Choose from four specific financial evaluation criteria:   
  - Basic Expense Analysis
  - Saving Suggestions
  - Budget Improvement Plan
  - Complete Financial Summary
- **Intelligent Financial Breakdown:** Automatically computes total expenditures, remaining monthly balance, and highlights peak spending categories.   
- **Practical Recommendations:** Delivers realistic monthly budget allocations and actionable cost-cutting advice styled in clear, beginner-friendly language.   
- **Localized Output:** Displays key monetary figures formatted in Indian Rupees (₹).   

## 🛠️ Tech Stack & Dependencies
- **Frontend / UI:** Streamlit   
- **Generative AI Model:** Google GenAI SDK (`google-genai`), using model `gemini-3.6-flash`
- **Environment Management:** `python-dotenv`
- **Language:** Python 3.x
